How SEC Tiebreakers Work

  1. 1

    Head-to-head record

    If the tied teams played each other this season, that result decides it directly - among three or more tied teams, this is each team's combined record against just the others in the tie.

  2. 2

    Combined record against common conference opponents

    Each tied team's record against every conference opponent that all of them played is compared, treating those shared opponents as a single group.

  3. 3

    Record against the next-highest-placed common opponent, working down the standings

    Starting from the best-placed team the tied group has in common, each tied team's record against that opponent is compared - if that's still even, the process repeats against the next-best common opponent, and so on down the standings.

  4. 4

    Strength of schedule

    The aggregate difficulty of each tied team's full-season schedule, based on opponents' win percentages.

  5. 5

    Scoring margin

    Point differential in games among the tied teams (often capped per game so a single blowout can't dominate the comparison).

Some tiebreaker steps involve factors like point differential that cannot be predicted before games are played, leading to uncertain outcomes in the scenarios above.
